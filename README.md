# The Tabernacle Concierge

Immersive Three.js landing page for concert venue concierge services. AWS QuickBuild Challenge entry.

<p align="center">
  <img src="imgs/tech-savvy-tabernacle-concierge.gif" alt="Demo" />
</p>

## Features

- Full-bleed venue photography with Three.js floating particle overlay
- Scroll-reveal animations on all content sections
- Upcoming event listings from The Tabernacle
- Package selection auto-fills the sign-up form
- Email validation with inline error feedback
- Guitar chord (Web Audio API) and stage light flash on successful sign-up

## Tech Stack

- **Vite** for dev server and build
- **Three.js** for WebGL particle system
- **Vanilla JS** for form logic, scroll observer, Web Audio synthesis
- **Nix** shell for reproducible dev environment
